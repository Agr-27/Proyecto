# Proyecto Clasificación Mundial de Futbol

"La Copa Mundial de Futbol es un evento muy importante a lo largo de todo el mundo, esta requiere un nivel de clasificación exacto y preciso del rendimiento de cada partido, de forma que se necesita llevar registro de los partidos, goles y puntos de cada selección de forma que en caso de empates se llegue a una decisión en base a estos datos registrados.

El proyecto Clasificación Mundial de Futbol tiene como objetivo el organizar de forma exacta los puntajes de 16 selecciones de forma que se puedan distinguir por: Nombre, Partidos Jugados (PJ), Partidos Ganados (PG), Partidos Perdidos (PP), Goles a favor (GF), Goles en contra (GC), Diferencia de Goles (DG) y por puntos totales obtenidos por cada selección."
