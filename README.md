# Proyecto Clasificación Mundial de Futbol

"El proyecto Clasificación Mundial de Fútbol tiene como objetivo organizar de forma exacta y transparente el desempeño deportivo de 48 selecciones nacionales en el torneo. La Copa Mundial requiere un control preciso del rendimiento en cada encuentro para determinar qué equipos avanzan a las siguientes fases y resolver posibles empates basándose estrictamente en las estadísticas registradas por cada selección, lo que permite a cualquier lector ver detalladamente el rendimiento de la selección durante el torneo de forma que cualquiera lo pueda comprender.

El programa se ejecuta en la terminal usando Python. Presenta un seguimiento detallado de cada encuentro, calcula automáticamente las posiciones del grupo y compara los resultados obtenidos por cada selección en tiempo real. Al finalizar la fase de grupos o el torneo, se desplegará una tabla con todos los datos de las selecciones que permitirá guardar la información registrada en un archivo de texto, así como desplegar en cualquier momento el historial completo de los torneos guardados.

Para lograr un control claro y preciso, el sistema organiza a las 24 selecciones de forma que se puedan evaluar por: Nombre de la selección, Partidos Jugados (PJ), Partidos Ganados (PG), Partidos Empatados (PE), Partidos Perdidos (PP), Goles a Favor (GF), Goles en Contra (GC), Diferencia de Goles (DG), Puntos Totales Obtenidos y Fase a la que llegaron (F)."
