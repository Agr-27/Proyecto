# Proyecto Clasificación Mundial de Futbol

"El proyecto Clasificación Mundial de Fútbol tiene como objetivo organizar de forma exacta y precisa el desempeño deportivo de 24 selecciones nacionales en el torneo. La Copa Mundial requiere un control preciso del rendimiento en cada encuentro para determinar qué equipos avanzan a las siguientes fases y resolver posibles empates basándose en las estadísticas registradas por cada selección, lo que permite a cualquier lector ver detalladamente el rendimiento de la selección durante el torneo de forma que cualquiera lo pueda comprender.

El programa se ejecuta en la terminal usando Python. Calcula automáticamente las posiciones del grupo y compara los resultados obtenidos por cada selección. Al finalizar la fase de grupos o el torneo, se desplegará una tabla con todos los datos de las selecciones que permitirá guardar la información registrada.

Para lograr un control claro y preciso, el sistema organiza a las 24 selecciones de forma que se puedan evaluar por: Nombre de la selección, Partidos Jugados (PJ), Partidos Ganados (PG), Partidos Empatados (PE), Partidos Perdidos (PP), Goles a Favor (GF), Goles en Contra (GC), Diferencia de Goles (DG), Puntos Totales Obtenidos (PT) y Fase a la que llegaron (F)."

## Algoritmo
Entrada: Solicitar que se ingresen 24 países (cualquiera)

El programa acomodara aleatoriamente los enfrentamientos entre estos países
Se solicitará al usuario escoger un ganador (el sistema asignará el resultado automáticamente con un rango máximo de 5 goles por selección)
Dependiendo los resultdos seran las estadísticas proyectadas al final de la simulacion (PG, PE, P, GF, GC, DG, PT y F)

Salida: Se desplegará en la consola los resultados
