# Proyecto Clasificación Mundial de Futbol

"El proyecto Clasificacion Mundial de Futbol tiene como objetivo el organizar de forma exacta los puntajes de 16 selecciones de forma que se puedan distinguir por: Nombre, Partidos Jugados (PJ), Partidos Ganados (PG), Partidos Perdidos (PP), Goles a favor (GF), Goles en contra (GC), Diferencia de Goles (DG) y por puntos totales obtenidos por cada seleccion.
